* About
Quick and dirty implementation of tesseract-ocr on a student project.

* Requirements:
#+begin_example sh
pacman -S tesseract tesseract-ocr tesseract-data-eng
#+end_example

* Usage:

First, init our venv and install necessary deps:

#+begin_example sh
python3 -m venv venv
source ./venv/bin/activate
pip3 install -r requirements.txt # a few moments later... ;)
#+end_example

** Example:

#+begin_example sh
chmod +x app.py
./app.py training_data/<img.jpg>

# Example Output:
# training_data/<img.jpg>: XXXXX[X] confidence: 76%
#+end_example

** Parameter Tuning:

NOTE: You can view/inspect what is going on with the images by opening
      '/tmp/enhanced_img_tmp.jpg' after the prog runs.

#+begin_example python
confidence_interval = 50

## crop and adjust the image, crop to selection...
## NOTE: GIMP is handy for tuning these...
# Convert to greyscale
image = image.convert("L")
# Resize the image (e.g., reduce to half the size)
image = image.resize((image.width // 2, image.height // 2))
# Crop the image to improve model focus
bounding_box = (94, 703, 1230, 947)
image = image.crop(bounding_box)
# Invert the colors
inverted_image = ImageOps.invert(image)
# Blurring removes a lot of noise
blurred_image = inverted_image.filter(ImageFilter.GaussianBlur(3)) # v1 value
# Enhance contrast
enhancer = ImageEnhance.Contrast(blurred_image)
enhanced_image = enhancer.enhance(9)  # v1 value

# Tweak how tesseract runs... In this case, we're looking for a 6-digit string
# of numbers 0-9 only.
custom_config = r'--oem 3 --psm 6 -c tessedit_char_whitelist=0123456789'
#+end_example
